# 🚀 Intune Bulk Assignment Tool
**Version:** 9.0 Production  
**File:** `Intune-Bulk-Assignment-9.0-Production.ps1`

## 📋 Overview
This PowerShell tool provides an interactive GUI to **bulk manage Microsoft Intune app assignments** using Microsoft Graph.  
It helps Intune admins:
- Quickly **assign groups to apps** as required.
- **Exclude groups** from selected apps.
- **Remove exclusions** across multiple apps.
- Filter by app names and get a live audit log.

---

## ✨ Features
✅ Connects securely to Microsoft Graph API with:
- `DeviceManagementApps.ReadWrite.All`
- `Group.Read.All`

✅ Windows Forms GUI with:
- Fields for Azure AD group name
- Text filter to narrow down apps
- Buttons to add group to apps, add as exclusion, or remove exclusion
- Real-time log display
- **Stop button** to interrupt long operations

✅ Summary pop-ups and detailed logs.

---

- Windows with PowerShell 5.1+
